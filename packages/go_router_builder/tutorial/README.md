# go_router_builder 教程

## 概述

本教程系列旨在帮助 Flutter 开发者全面掌握 `go_router_builder` 的使用。`go_router_builder` 是一个为 Flutter 的 `go_router` 包提供类型安全路由的代码生成工具，通过编译时类型检查，让路由导航更加安全和高效。

### 教程目标

- 理解类型安全路由的核心概念和优势
- 掌握路由参数的定义和使用方法
- 学会使用导航和重定向功能
- 了解高级特性如类型转换、转场动画、ShellRoute 等
- 掌握错误处理和最佳实践

### 适合人群

- Flutter 开发者
- 使用 `go_router` 进行路由管理的开发者
- 希望提升代码类型安全性的开发者

## 教程目录

本教程系列包含以下 5 个章节，建议按顺序学习：

1. [基础入门与概述](1-基础入门与概述.md) - 了解 `go_router_builder` 的基本概念、安装配置和基本路由定义
2. [路由参数详解](2-路由参数详解.md) - 深入学习路径参数、查询参数和额外参数的使用
3. [导航与重定向](3-导航与重定向.md) - 掌握导航方法、返回值处理和重定向机制
4. [高级特性](4-高级特性.md) - 探索类型转换、转场动画、ShellRoute 和相对路由等高级功能
5. [错误处理与最佳实践](5-错误处理与最佳实践.md) - 学习错误处理、测试方法和开发最佳实践

## 教程详细说明

### [1. 基础入门与概述](1-基础入门与概述.md)

**学习目标**：

- 理解类型安全路由的核心价值
- 掌握 `go_router_builder` 的安装和配置
- 学会定义基本路由和路由树结构
- 了解代码生成的工作流程

**主要内容**：

- 为什么需要类型安全路由
- 安装配置和代码生成
- 基本路由定义（`GoRouteData`、`build` 方法）
- 路由注解（`@TypedGoRoute`）
- 路由树结构
- `GoRouter` 初始化

**适合人群**：初学者，首次接触 `go_router_builder` 的开发者

### [2. 路由参数详解](2-路由参数详解.md)

**学习目标**：

- 理解三种参数类型的区别和使用场景
- 掌握路径参数、查询参数和额外参数的定义方法
- 学会参数类型转换
- 了解参数解析流程

**主要内容**：

- 路径参数（Path Parameters）
- 查询参数（Query Parameters）
- 额外参数（Extra Parameters）
- 参数类型对比和选择指南
- 混合参数使用
- URL 参数解析流程
- 参数类型转换

**适合人群**：已掌握基础概念的开发者，需要深入了解参数使用的开发者

### [3. 导航与重定向](3-导航与重定向.md)

**学习目标**：

- 掌握各种导航方法的使用场景
- 学会处理路由返回值
- 理解全局重定向和路由级重定向的区别
- 了解相对路由导航

**主要内容**：

- 导航方法（`go`、`push`、`goRelative`、`pushRelative`）
- 类型安全的导航
- 返回值处理（`await push`）
- 全局重定向配置
- 路由级重定向实现
- 相对路由导航

**适合人群**：已掌握路由参数使用的开发者，需要实现复杂导航逻辑的开发者

**主要内容**：

**适合人群**：已掌握基础功能的开发者，需要实现高级功能的开发者
